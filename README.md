# Cult Up Gaming Mods

Public source repository for Cult Up Gaming game mods.

## Structure

Mods are organized by game under the `mods` directory.

For example:

`mods/rdr1/red-dead-knifemare`

Each mod keeps its own source, build files, release scripts, assets, and documentation inside its mod directory.

Third-party tools that are not redistributed with a mod are not included in this repository.
